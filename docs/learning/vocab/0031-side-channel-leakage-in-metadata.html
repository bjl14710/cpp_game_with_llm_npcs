Vocab 0031 — Side-Channel Leakage in Metadata

Terms from lesson 0032 / issue #200.

side channel
Information reaching an observer through a path nobody designed as a communication path. Here the [[MOOD:]] tag: the model kept its secret in the prose and lost it in the metadata.
separability
Whether one group's outputs can be told apart from another's. Chosen over "never emits X" because the fix for a leak is to hide the signal in noise, not delete it — deleting it produces bland androids and optimises the wrong thing.
exploit-derived metric
A statistic whose shape comes from the attack it is meant to detect. "Sort the faces by hostility and accuse the top one" is a rank, so the statistic is a rank. If you cannot state the attack in one sentence, the metric is measuring something adjacent.
rank permutation test
p-value as the fraction of the population scoring at least as high as the subject. No distributional assumption, no dependency, and it restates in words: "five residents in ten look at least this hostile".
total variation distance (TVD)
0 to 1 measure of how far apart two distributions are; 0 identical, 1 nothing in common. Used over chi-square because it needs no expected-count floor at small n and the number is directly interpretable.
collapsed statistic
A summary that reduces a distribution to one number and is therefore blind to structure in the other dimensions. The rank test alone reported a clean PASS and could not see that the killer was conspicuous in a different mood.
cover (in a hidden-role design)
Innocent agents behaving enough like the guilty one that the guilty one's behaviour stops being a unique signal. Requires the groups to LOOK ALIKE — measured here at TVD 0.59 apart, so the intended cover is not functioning even though nothing leaks.
undocumented defence
A protection that works for a reason other than the one the design describes. The killer hides by being unremarkable, not by being camouflaged among deflectors — real, measurable, and invisible to anyone reading the role files.
CANNOT EVALUATE
A third outcome beside pass and fail, for when the gate could not run at all. Collapsing it into a pass makes a broken gate look green; collapsing it into a failure sends someone debugging content when the model server is down.
scaffold exit code
An unimplemented gate returning non-zero, so it can never be mistaken for a passing one while sitting in a pipeline being trusted.
self-reported n
Sample size printed beside the verdict. A probe that hides its own n is worse than no probe, because its numbers get quoted without their error bars.
ordering-stable finding
A conclusion that survives run-to-run noise because it depends on rank rather than magnitude. Across two runs the values moved (0.85 → 0.59) but the ordering did not — so the ordering is the finding.
