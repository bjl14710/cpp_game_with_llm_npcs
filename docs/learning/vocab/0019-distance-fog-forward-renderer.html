Vocab: Distance Fog in a Forward Renderer

forward renderer
A pipeline that shades each object as it's drawn (as opposed to deferred rendering's G-buffer pass). Fog composes directly into each draw's fragment shader — no extra pass needed.
squared-exponential fog
1 - exp(-(d·k)²): flat near the camera, steep roll-off at distance. The middle ground between linear fog's hard "wall" and plain exponential's everywhere-dulling.
fog density
The single scalar (0.006 here) controlling where the roll-off lands. Tune against two anchor distances: the gameplay bubble that must stay crisp and the world edge that should vanish.
uniform
A shader parameter constant across a draw call (fogColor, fogDensity, per-frame cameraPos). Set via SetShaderValue; cache the location integer instead of looking it up by string every frame.
rlgl batch
raylib's immediate-mode geometry accumulator behind DrawCube/DrawPlane/ DrawCylinder. Uses the current shader (BeginShaderMode), not any material — the second draw path a scene-wide effect must cover.
material shader assignment
Setting model.materials[i].shader after load so DrawMesh uses a custom shader. Shared across models by design; the owner unloads it exactly once.
CPU vs GPU skinning
CPU skinning (raylib 5.5) poses vertices in memory before drawing — custom shaders see finished geometry. GPU skinning poses in the vertex shader — custom shaders must reimplement it or characters freeze in bind pose.
