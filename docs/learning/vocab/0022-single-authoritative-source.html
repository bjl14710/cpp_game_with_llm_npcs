Vocab: The Single Authoritative Source

single authoritative source
The one place a quantity is computed or owned. Every other user derives from it rather than reconstructing its own copy, so the value cannot disagree with itself.
moonwalk bug
This codebase's name (from #61) for the failure where two consumers each rebuild "the same" value from raw inputs and drift apart — like a character sliding backward while animating a forward walk.
reconstruction
Recomputing a value beside its real source instead of reading the source. The seed of a moonwalk: two reconstructions are only ever coincidentally equal.
derived value
A value computed on demand from an owner (defaultYaw = player.yawDeg + 180). Contrast with a cached copy, which can go stale when the owner changes.
latch
Capturing a decision at the instant its inputs are meaningful (the mouse press) and holding it until a defined release, rather than re-deriving it each frame from data that has since moved.
sample-per-frame
Re-answering, every tick, a question that was actually settled at an earlier event. The time-domain form of reconstruction; the fix is to latch.
shortest angular delta
The signed difference between two angles wrapped to [-180°, 180°] (shortestAngleDelta), so an ease or turn always takes the short arc instead of unwinding the long way round.
designed-out bug
A defect removed by structure rather than patched by a guard — after #91 no weapon can mis-aim, because there is no second aim vector to be wrong.
