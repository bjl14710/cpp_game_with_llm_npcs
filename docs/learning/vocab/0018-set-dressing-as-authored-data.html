Vocab: Set Dressing as Authored Data

set dressing
Non-interactive world objects (parked cars, dumpsters, bins) placed purely to make a scene feel inhabited. Film term; in games it should ride existing pipelines, not spawn new ones.
authored data
Hand-written, reviewable placement rows (the Building list) as opposed to procedural or runtime-generated content. Diffable, testable, and the single source for both rendering and collision here.
collision honesty
The property that an object's collider matches its visible footprint — no walk-through props (collider missing) and no invisible walls (collider oversized). Both directions get a test.
clearance test
A data-driven test asserting that designated walkable points (persona home spots, crossing centers) keep a clear circle of the actor's collision radius. Guards pathing against future set dressing.
identity orientation
The direction a model faces when drawn with no rotation. A pipeline without rotation support constrains placement to spots where identity orientation reads correctly (Z-long cars on Z-running streets).
probe point
A coordinate inside an obstacle's AABB used by the completeness test to prove the collider exists — chosen inside the box, not on its edge, so the check can't pass by luck.
