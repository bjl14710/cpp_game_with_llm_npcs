Vocab 0030 — One Implementation Across a Language Boundary

Terms from lesson 0031 / issue #304.

invalid instrument
A measurement apparatus that produces plausible numbers about the wrong thing. Distinct from a bug: a bug gives a wrong answer you can eventually notice, an invalid instrument gives a believable one indefinitely. A Python copy of prompt assembly would be one, because placement is what the probe measures.
behaviour export
Crossing a language boundary by having the owning language PRINT its result — a subprocess plus JSON — rather than re-deriving it. persona_prompt --state and --parse are the two directions of the same exchange.
hand-synced duplicate
A copy kept in step by discipline alone. bench_npc_models.py's mood keyword list is one and says so in its own comment — the codebase's own counterexample.
fail closed (at a measurement boundary)
Refusing to produce output on bad input, where the product would degrade and continue. Justified by a different worst outcome: for a game, a lost character; for a measurement, a number that means nothing.
zero-byte refusal
Printing no partial result on failure, so a broken fixture can never be mistaken for data.
identity check
Asserting a new path is byte-for-byte equal to an existing one in the case where they should agree. Pins a seam without re-testing what is behind it — here, that an uncast persona renders identically through both modes.
residue testing
Testing only what an existing harness does not already cover, having first established precisely what it does. The core contract is pinned in doctest; the shell script covers whether the tool passes the right arguments to it.
pointer-into-argument
A function returning a pointer into a container it was passed, so the container must outlive the result. findRole is one, and the inline form dangles.
