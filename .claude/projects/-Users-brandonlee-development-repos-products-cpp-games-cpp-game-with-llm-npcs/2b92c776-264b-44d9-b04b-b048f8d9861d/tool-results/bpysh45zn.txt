What Are IQ Samples?</span>\n    <span class=\"section-label\">(read)</span>\n  </label>\n</h2>\n\n<p>Radio signals are waves. To capture them digitally a receiver doesn't just sample the amplitude — it captures two components simultaneously: the <strong>In-phase (I)</strong> and <strong>Quadrature (Q)</strong> channels, offset by 90 degrees. Together they describe the full vector of the signal at every moment.</p>\n\n<p>The RTL-SDR dongle produces these as pairs of unsigned 8-bit values (called <strong>UC8</strong> — Unsigned Complex 8-bit). Each byte represents one channel, biased around 127.5 (so 0 = −1.0, 127 ≈ 0, 255 = +1.0). The USB transfer gives readsb a raw byte stream: <code>I, Q, I, Q, I, Q, …</code></p>\n\n<p>For Mode S decoding, readsb doesn't care about phase — it only cares about <strong>signal magnitude</strong> (signal strength at each moment). Magnitude is calculated as:</p>\n\n<pre><span class=\"cm\">// mathematically: mag = sqrt(I² + Q²), normalized to 0..1</span>\nfI = (raw_I - 127.5) / 127.5;  <span class=\"cm\">// normalize to -1..+1</span>\nfQ = (raw_Q - 127.5) / 127.5;\nmagsq = fI*fI + fQ*fQ;\nmag   = sqrtf(magsq);           <span class=\"cm\">// 0..1 range</span>\n\n<span class=\"cm\">// stored as uint16_t scaled to 0..65535</span>\noutput = (uint16_t)(mag * 65535.0f + 0.5f);</pre>\n\n<div class=\"callout\">\n  <strong>Why uint16_t?</strong> A 16-bit integer gives enough resolution to distinguish signal from noise, avoids floating-point math in the hot demodulator loop, and keeps the buffer compact — 12 buffers × 128 KiB each still fits comfortably in L3 cache.\n</div>\n\n<!-- ═══════════════════════════════════════════════════════════ -->\n<h2>\n  <label class=\"section-header\">\n    <input type=\"checkbox\" class=\"section-check\" data-section=\"2\">\n    <span>2. The Lookup Table Trick — convert_uc8_nodc()</span>\n    <span class=\"section-label\">(read)</span>\n  </label>\n</h2>\n\n<p>Computing <code>sqrt()</code> for every sample pair at 2.4 million samples per second would be expensive. readsb pre-computes all 256×256 = 65536 possible (I, Q) combinations at startup and stores the result in a table: <span class=\"filepath\">convert.c:35</span></p>\n\n<pre><span class=\"kw\">static</span> <span class=\"ty\">uint16_t</span> *uc8_lookup;   <span class=\"cm\">// 65536 entries, each precomputed</span>\n\n<span class=\"kw\">for</span> (<span class=\"kw\">int</span> i = <span class=\"num\">0</span>; i &lt;= <span class=\"num\">255</span>; i++) {\n    <span class=\"kw\">for</span> (<span class=\"kw\">int</span> q = <span class=\"num\">0</span>; q &lt;= <span class=\"num\">255</span>; q++) {\n        fI = (i - <span class=\"num\">127.5</span>) / <span class=\"num\">127.5</span>;\n        fQ = (q - <span class=\"num\">127.5</span>) / <span class=\"num\">127.5</span>;\n        magsq = fI * fI + fQ * fQ;\n        <span class=\"kw\">if</span> (magsq &gt; <span class=\"num\">1</span>) magsq = <span class=\"num\">1</span>;   <span class=\"cm\">// clamp to valid range</span>\n        <span class=\"cm\">// store as uint16_t</span>\n        uc8_lookup[(i * <span class=\"num\">256</span>) + q] = (<span class=\"ty\">uint16_t</span>)(sqrtf(magsq) * <span class=\"num\">65535.0f</span> + <span class=\"num\">0.5f</span>);\n    }\n}</pre>\n\n<p>At runtime, each sample pair is just a single table lookup: <span class=\"filepath\">convert.c:81</span></p>\n\n<pre>mag = uc8_lookup[*in++];   <span class=\"cm\">// *in is uint16_t* pointing to interleaved I,Q pairs</span>\n*mag_data++ = mag;</pre>\n\n<p>The loop also unrolls 4× to hint to the CPU's instruction scheduler:</p>\n\n<pre><span class=\"kw\">for</span> (i = <span class=\"num\">0</span>; i &lt; (nsamples / <span class=\"num\">4</span>); ++i) {\n    DO_ONE_SAMPLE;  DO_ONE_SAMPLE;\n    DO_ONE_SAMPLE;  DO_ONE_SAMPLE;   <span class=\"cm\">// 4 samples per loop iteration</span>\n}</pre>\n\n<div class=\"callout tip\">\n  <strong>DC filter variant:</strong> When <code>--dcfilter</code> is passed, the slower <code>convert_uc8_generic()</code> is used instead. It applies a 1Hz IIR high-pass filter that removes any DC bias from the SDR hardware, at the cost of a <code>sqrtf()</code> per sample and two extra state variables (<code>z1_I</code>, <code>z1_Q</code>). The function pointer <code>RTLSDR.converter</code> points to whichever variant was selected in <code>rtlsdrOpen()</code>.\n</div>\n\n<!-- ═══════════════════════════════════════════════════════════ -->\n<h2>\n  <label class=\"section-header\">\n    <input type=\"checkbox\" class=\"section-check\" data-section=\"3\">\n    <span>3. mag_buf — What the Buffer Carries</span>\n    <span class=\"section-label\">(read)</span>\n  </label>\n</h2>\n\n<p>After conversion, the magnitude data lands in a <code>struct mag_buf</code> — <span class=\"filepath\">readsb.h:506</span>. The Ring Buffer — How Reader and Decoder Share Data</span>\n    <span class=\"section-label\">(read)</span>\n  </label>\n</h2>\n\n<p>The reader (USB callback) and decoder (demod thread) run concurrently.
