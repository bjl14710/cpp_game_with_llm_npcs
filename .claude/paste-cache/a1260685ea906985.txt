/idea

Goal: A player-facing journal that collects facts learned from NPCs and
surfaces contradictions between what different NPCs have said.

Context: This is a reader of the same shared fact store the gossip ticket
writes to — not a separate tracking system. The journal should only ever
show facts the player was personally told (filtered by source/hearer), so
it doesn't spoil gossip the player wasn't part of.

Scope:
1. Journal UI — list facts the player has learned, grouped by subject,
   using the existing menu system from the earlier menu/dialogue ticket
   rather than a new UI stack.
2. Contradiction detection — compare facts sharing the same normalized
   subject field for conflicting content (e.g. two different times given
   for the same event) and flag them visibly to the player.
3. Read path only — this ticket should not need to modify how facts are
   written; if it does, that's a sign the fact schema from the gossip
   ticket needs a field added, not that the journal needs its own store.
